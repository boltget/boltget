---
title: How we measure
description: The method behind the benchmark chart, in short.
---

Each test downloads the same file several times on one machine and one line, taking turns between the two download managers, and the chart shows the median time. Both run at their default settings, and every file is checked against its known SHA-256.

A difference counts only when every run of one is faster than every run of the other. `boltget bench` runs the same kind of measurement on your own network; the [CLI docs](/docs/cli/#measure-your-own-network) show how.
