Boltget is a download manager built for speed. It splits each file across several connections, keeps every connection busy until the last byte, and resumes where it stopped, even after a crash or a power cut.

It comes as a desktop app, now in preview on Windows with macOS and Linux to follow, and as the `boltget` command-line tool, which works on its own or alongside the app. Both are on the [download page](/download/).

## Start here

- [Install](/docs/getting-started/): install the app, or get the command-line tool, and make your first download.
- [Using the CLI](/docs/cli/): pause and resume, link refresh, limits, checksums, proxies and benchmarks.
- [Exit codes and JSON](/docs/cli/scripting/): for scripts.

What comes next is in the [roadmap](https://github.com/boltget/boltget/blob/main/docs/ROADMAP.md). These pages are for people using Boltget; the design documents for contributors live in the repository's [`docs/` folder](https://github.com/boltget/boltget/tree/main/docs).
