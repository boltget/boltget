Boltget is a download manager built for speed. It splits each file across several connections, keeps every connection busy until the last byte, and resumes where it stopped, even after a crash or a power cut.

## What exists today

Boltget is at **v0.1**: the download engine and the `boltget` command-line tool, published as a [download](/download/) for Windows (and a preview build for Linux). There is no installer yet.

| Milestone | What it brings |
|---|---|
| v0.1 (now) | Engine and CLI: segmented downloads, adaptive connections, crash-safe resume, link refresh, speed limits, checksums, proxies, cookies, `boltget bench` |
| v0.2 | The Windows desktop app |
| v0.3 | Browser extension for Chrome, Edge and Firefox |
| v0.4 | Video and audio downloads |
| v0.5 | Scheduler, queues and polish |
| v1.0 | Public launch, signed installer |

The full plan is in the [roadmap](https://github.com/boltget/boltget/blob/main/docs/ROADMAP.md).
