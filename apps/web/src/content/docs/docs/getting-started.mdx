The v0.1 preview is the `boltget` command-line tool. There is no installer yet: download the zip and run it from a folder, or build it from source.

## Download a release

Get `boltget-<version>-windows-x64.zip` from the [download page](/download/) (a Linux `tar.gz` is there too, as a preview build). Unpack it and run `boltget` from that folder:

```powershell
tar -xf boltget-0.1.0-windows-x64.zip
cd boltget-0.1.0-windows-x64
.\boltget --version
```

To run it from anywhere, copy `boltget.exe` to a folder on your `PATH`. It needs no other files.

The download page lists the SHA-256 of every file and how to check it, along with the build provenance (`gh attestation verify`). The builds are not code-signed yet, so Windows SmartScreen may warn the first time you run `boltget.exe`; signed builds arrive with v1.0.

## Build from source

It takes a few minutes the first time.

### Requirements

- **Rust**, installed with [rustup](https://rustup.rs). The repository pins the exact toolchain in `rust-toolchain.toml`, and rustup picks it up on its own.
- **Windows:** Visual Studio Build Tools with the "Desktop development with C++" workload, for the MSVC toolchain.
- **Linux:** a C compiler (for example `build-essential` on Debian and Ubuntu).
- **Git**, to clone the repository.

### Build

```sh
git clone https://github.com/boltget/boltget.git
cd boltget
cargo build --release -p boltget-cli
```

The binary is `target/release/boltget` (`boltget.exe` on Windows). To put it on your `PATH` instead:

```sh
cargo install --locked --path crates/cli
```

You can also run it without installing: `cargo run --release -p boltget-cli -- get <url>`. To rebuild a release exactly, see [BUILDING.md](https://github.com/boltget/boltget/blob/main/docs/BUILDING.md).

## First download

```sh
boltget get https://example.com/file.iso
```

`boltget` shows a progress bar with the speed, the time left and a map of the segments. Without `-o`, the file goes to the current directory under the name the server gives it. It never overwrites an existing file unless you pass `--overwrite`.

Press **Ctrl-C** to pause. The download keeps its progress and an id:

```sh
boltget list
boltget resume 1
```
