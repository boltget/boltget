## Install the app

1. Download the installer from the [download page](/download/). It runs on 64-bit Windows 10 and 11.
2. Run it. It installs Boltget for your account, without administrator rights, and adds it to the Start menu. While Boltget is in preview the installer is not signed yet, so Windows SmartScreen asks once: choose **More info**, then **Run anyway**.
3. Add a download: click **Add download**, press **Ctrl+N**, or paste a link with **Ctrl+V**. Boltget looks at the link, shows the file's name, size and whether it can resume, and **Enter** starts it.

Closing the window keeps your downloads going in the tray. Uninstall it from Windows Settings like any other app; your downloaded files always stay.

## Get the command-line tool

The `boltget` command-line tool comes as its own download. Get `boltget-<version>-windows-x64.zip` from the [download page](/download/) (a Linux `tar.gz` is there too). Unpack it and run `boltget` from that folder:

```powershell
tar -xf boltget-<version>-windows-x64.zip
cd boltget-<version>-windows-x64
.\boltget --version
```

To run it from anywhere, copy `boltget.exe` to a folder on your `PATH`. It needs no other files. While the app is running, `boltget` sends its downloads to the app, so both show the same list.

The download page lists the SHA-256 of every file and how to check it.

## Build from source

It takes a few minutes the first time.

### Requirements

- **Rust**, installed with [rustup](https://rustup.rs). The repository pins the exact toolchain in `rust-toolchain.toml`, and rustup picks it up on its own.
- **Windows:** Visual Studio Build Tools with the "Desktop development with C++" workload, for the MSVC toolchain.
- **Linux:** a C compiler (for example `build-essential` on Debian and Ubuntu).
- **Git**, to clone the repository.

### Build

```sh
git clone https://github.com/boltget/boltget.git
cd boltget
cargo build --release -p boltget-cli
```

The binary is `target/release/boltget` (`boltget.exe` on Windows). To put it on your `PATH` instead:

```sh
cargo install --locked --path crates/cli
```

You can also run it without installing: `cargo run --release -p boltget-cli -- get <url>`. To rebuild a release exactly, see [BUILDING.md](https://github.com/boltget/boltget/blob/main/docs/BUILDING.md).

## First download

```sh
boltget get https://example.com/file.iso
```

`boltget` shows a progress bar with the speed, the time left and a map of the segments. Without `-o`, the file goes to the current directory under the name the server gives it. It never overwrites an existing file unless you pass `--overwrite`.

Press **Ctrl-C** to pause. The download keeps its progress and an id:

```sh
boltget list
boltget resume 1
```
