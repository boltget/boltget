# Getting help

BoltGet is pre-alpha and has no releases yet, so support today is mostly about the design. This page tells you where to go so your question reaches the right people.

## Where to ask

| You want to... | Go to |
|---|---|
| Ask a question, get help using BoltGet, share an idea, discuss the design | [GitHub Discussions](https://github.com/boltget/boltget/discussions) |
| Report a reproducible bug | [Bug report form](https://github.com/boltget/boltget/issues/new?template=bug_report.yml) |
| Request a concrete feature | [Feature request form](https://github.com/boltget/boltget/issues/new?template=feature_request.yml) (check the [roadmap](docs/ROADMAP.md) and [non-goals](docs/VISION.md#non-goals) first) |
| Report a security vulnerability | **Privately**, as described in [SECURITY.md](SECURITY.md). Never in a public issue. |
| Report a Code of Conduct violation | [conduct@boltget.app](mailto:conduct@boltget.app), see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |
| Contribute code or docs | [CONTRIBUTING.md](CONTRIBUTING.md) |

**Issues are for actionable work** (bugs and accepted features). Questions opened as issues will be moved to Discussions.

## Discussions categories

- **Q&A:** how do I..., why does...
- **Ideas:** feature ideas before they become issues.
- **Design:** feedback on the documents in [docs/](docs/README.md).
- **Benchmarks:** share your results and setups.
- **Show and tell:** scripts, integrations, anything built around BoltGet.
- **Announcements:** releases and project news (maintainers only).

## Before you ask

- Search Discussions and Issues; your question may already have an answer.
- Read the relevant doc: [docs/README.md](docs/README.md) lists them all. User documentation will live at [boltget.app/docs](https://boltget.app/docs) once the website is up.
- For problems with a download, include: BoltGet version, Windows version, the type of site (no need to share private URLs), what you expected and what happened, and logs from Settings → About → Open logs folder (check them for private URLs first; BoltGet redacts query strings by default).

## What we cannot help with

- Downloading from a specific site that blocks downloads or requires an account you do not have.
- DRM-protected content (BoltGet does not support it, by design).
- Unofficial builds or repackages of BoltGet. Only builds from [GitHub Releases](https://github.com/boltget/boltget/releases) and [boltget.app](https://boltget.app) are official.

Everyone helping here is a volunteer. Be patient and kind; it makes everything faster.
